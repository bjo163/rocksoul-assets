# MoonWitness Brand Assets

Canonical editable vector identity for the MoonWitness × Rocksoul ecosystem.

## Rule

SVG is the source of truth. Raster exports used by applications must be generated from these SVG sources, never edited independently.

## Primary files

- `logo-mark.svg` — symbol only
- `logo-horizontal.svg` — default product header lockup
- `logo-stacked.svg` — campaign/cover lockup
- `wordmark.svg` — editable wordmark
- `logo-monochrome.svg` — single-color reproduction
- `rocksoul-lockup.svg` — ecosystem lockup
- `favicon.svg` — browser icon
- `app-icon.svg` / `app-icon-maskable.svg` — application/PWA vector sources
- `apple-touch-icon.svg` — iOS source asset
- `social-avatar.svg` — square social/profile mark
- `og-card.svg` — 1200×630 social share source
- `safari-pinned-tab.svg` — monochrome pinned-tab source
- `site.webmanifest` — web app icon contract

See `brand-assets.json` for machine-readable inventory and semantics.
