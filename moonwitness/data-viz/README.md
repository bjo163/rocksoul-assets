# MoonWitness Data-Viz Pack

20 reusable charts, network/lineage primitives, legends, nodes, edge states, evidence matrices, heatmaps, annotation components, and EVENT-specific topology/context visuals.

LEGEND-oriented canonical visuals:
- `event-topology` — event → claim/evidence/source/place/artifact/foreign-reference topology.
- `historicity-band` — scoped confidence separated from uncertainty and alternatives.
- `place-material-context` — event anchoring to place, artifact, and source provenance.
- `cross-domain-relations` — qualified EVENT links to PERSON, STORY/MYTH, TEXT/LAW, and PERSPECTIVE.

These are semantic references, not screenshots; product consumers should prefer data-driven Rocksoul UI components for live records.
