# Licensing and Reuse

## Current repository status

This repository is public, but it currently has **no repository-wide LICENSE file**.

Public visibility does not automatically grant permission to copy, redistribute, modify, sublicense, or commercially reuse the assets.

## Until a license is selected

Treat the contents as:

- available for inspection and collaboration within the Rocksoul / MoonWitness project context;
- not automatically licensed for unrelated external redistribution or commercial reuse.

## Why this is explicit

A mature asset repository should not let users infer rights from a GitHub visibility setting.

Brand marks, product identity, generated artwork, sound assets, and design-system sources may require different reuse rules than implementation code.

## Future licensing decision

If the project later adopts a license, document:

- code/tooling license;
- visual asset license;
- brand/trademark restrictions;
- third-party font or media constraints;
- whether generated derivatives inherit the source asset terms.

Do not add a generic open-source license to the repository without confirming that it matches the intended rights for brand and visual assets.
