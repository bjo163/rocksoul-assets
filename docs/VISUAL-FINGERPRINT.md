# Visual Fingerprint — ROCKSOUL / MoonWitness

## Purpose

The system must remain recognizable when logo, product name, and explicit brand text are removed. Distinctiveness is structural and semantic, not a dark-background-plus-crimson recipe.

## Frozen signature traits

1. Evidence and provenance traces are first-class visual structure.
2. Mono metadata rhythm separates machine facts from narrative copy.
3. Graph uncertainty uses fragmentation, ghosting, boundary completeness, and text qualifiers.
4. Operator and forensic surfaces favor rails, inspectors, topology, and evidence context over generic card grids.
5. Crimson is a controlled interruption with distinct Brand, Signal, and Critical meanings.
6. Archive/editorial surfaces use document logic and asymmetric reading structure.
7. ROCKSOUL physical marks are opt-in interventions layered over the rigorous MoonWitness base.
8. Surface personalities remain related but materially different in density, typography, composition, and material intensity.

## Generic-pattern watchlist

Common UX patterns are allowed when content requires them, but may not become default identity:

- four equal KPI cards
- generic SaaS sidebar + topbar + cards
- identical rounded cards everywhere
- glassmorphism without semantic purpose
- gradient orb hero
- black minimalism with no evidence/provenance structure
- generic node-link graph
- donut chart as default dashboard identity
- blue observability palette presented as brand identity

## Blind review

For each canonical reference:

1. remove logo/product/provider names;
2. render normal, grayscale, low-saturation, and thumbnail/silhouette variants;
3. compare against an intentionally generic internal control;
4. record evidence for structure, semantic language, typography, graph distinctiveness, material discipline, personality, brand dependence, and generic-SaaS risk.

A screen passes when reviewers can explain the structural traits that identify the system without relying on logo or crimson alone.

## Scorecard

Use 0–2 per dimension with screenshot/specimen evidence:

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Structural identity | generic | partial | clear canonical archetype |
| Semantic visual language | cosmetic | mixed | evidence/provenance semantics explicit |
| Typographic identity | generic | partial roles | display/body/mono roles deliberate |
| Graph distinctiveness | generic links | partial | canonical geometry/rhythm/uncertainty |
| Material discipline | decorative | mixed | personality-scoped intervention |
| Surface personality | indistinct | recognizable | unmistakable but related |
| Brand dependence | logo/color-dependent | mixed | structure survives brand stripping |
| Generic-SaaS risk | high | moderate | low |

A passing reference requires no dimension at 0 and must explicitly pass Brand Dependence and Generic-SaaS Risk.
