# PERSPECTIVE Visual Grammar

Canonical owner: `rocksoul-assets` for visual source and delivery.  
Semantic owner: `rocksoul-jizz` for PERSPECTIVE intelligence.  
Reusable implementation: `rocksoul-ui`.

## Pack

`moonwitness/perspective-intelligence-pack/` defines eight canonical SVG references with generated PNG derivatives:

| Asset | Intended meaning | Must not imply |
|---|---|---|
| `perspective-constellation` | multiple actor views around one phenomenon | truth distance or causal distance |
| `world-perspective-field` | geographic coverage of observed perspectives | population weighting or representativeness |
| `divergence-compass` | field divergence/convergence under uncertainty | truth score or winner |
| `zigzag-signal-timeline` | derived movement in perspective signals | underlying EVENT truth |
| `actor-framing-matrix` | where actor classes and framing dimensions are observed | support/opposition unless position is explicitly encoded |
| `provenance-flow` | issue → source → observation → perspective → signal → insight traceability | automatic canonicalization |
| `reaction-spectrum` | distribution of source-scoped reaction types | event status or moral judgment |
| `coverage-radar` | relative research coverage dimensions | evidence strength or confidence |

## First-class PERSPECTIVE identity

The visual system also defines:

- `moonwitness/icons/svg/domain/perspective.svg`
- `moonwitness/correlation-semantics-pack/svg/node-perspective.svg`

PERSPECTIVE is not rendered as CASE. TEXT uses the `source` product icon and LAW uses `legal`; repository labels such as RGBL, AWS and JIZZ are not semantic domains.

## Runtime rule

Static assets are canonical visual references and fallbacks. Live products should render data-driven equivalents through `rocksoul-ui` so new JIZZ records do not require image regeneration.

## Accessibility

Every graph requires a semantic text/data equivalent. Color is never the only encoding. Reduced-motion preferences remain authoritative for animated consumers.

## Guardrail

> **JIZZ owns the view. Not the thing.**

Visual separation, size, color, density, divergence and salience must never be presented as final truth, historical fact, legal verdict, identity resolution, or reviewed cross-domain relationship.
