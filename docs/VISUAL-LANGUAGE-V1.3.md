# MoonWitness Visual Language v1.3

v1.3 moves investigation semantics out of monolithic screen references into reusable pack assets.

## Coverage

Evidence inspection → correlation → workflow → collaboration → AI → authorization → privacy → integrity → export → communication → runtime delivery.

## Semantic guarantees

- Evidence annotations distinguish verified, disputed and redacted regions.
- Correlation edge vocabulary distinguishes support, contradiction, reference, identity, temporal, location, legal, review, inference, uncertainty and unresolved relationships.
- Privacy/redaction and legal/jurisdiction assets are semantic.
- Runtime motion requires reduced-motion behavior.
- Developer distribution is generated, not hand-maintained.

## Canonical index

`moonwitness/asset-packs.json` → 41 pack families.
