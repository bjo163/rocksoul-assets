# Native Penpot design contract

`penpot/primitives/primitives.json` is the canonical token layer: its density modes are editorial, comfortable, and compact. `penpot/components/components.json` is the reusable component/variant inventory. Typography is frozen to display/body/mono families with explicit fallback stacks and licensing recorded in the component manifest. Generated reference boards under `penpot/generated` and golden-case visuals are inspection outputs only; editable components remain in the primitives/components sources.

Run `node tools/assets/validate-penpot-contract.mjs` before export.
